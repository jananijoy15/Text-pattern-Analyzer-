🔤 Text Pattern Analyzer

Text Pattern Analyzer is a simple web-based Text Analysis application that analyzes characters and patterns in the entered text.

Live Application Link 
https://jananijoy15.github.io/Text-pattern-Analyzer-/

✨ Features

- 📝 Analyze text input
- 🔤 Count vowels
- 🔡 Count consonants
- 🔢 Count characters
- 🔄 Check whether text is a palindrome
- 🔍 Detect repeated characters
- 📊 Display character patterns
- 📱 Mobile-friendly responsive interface
- ⚡ Fast processing using JavaScript

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

🚀 How to Use

1. Open the application in a web browser.
2. Enter a word or sentence.
3. Click the Analyze Text button.
4. The application analyzes the characters and patterns.
5. View the vowel, consonant, palindrome, and repeated-character results.

💡 Example

Input:

madam

Output:

Vowels: 2
Consonants: 3
Characters: 5

Palindrome:
Yes! The entered text is a palindrome.

📊 Analysis

Feature| Description
Vowels| Counts A, E, I, O and U
Consonants| Counts alphabetic consonants
Characters| Counts characters excluding spaces
Palindrome| Checks whether text reads the same backwards
Repeated Characters| Finds characters appearing more than once
